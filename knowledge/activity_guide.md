# Activity guide

What listeners usually want for common activities. Each section gives a target energy, mood tags that fit, and lyric guidance.

## studying
Aliases: study, homework, focus, concentrate, reading, deep work, coding, exam prep
Target energy: 0.35
Instrumental: prefer (vocals pull attention away from reading)
Mood tags: focused, calm, cozy, steady
Explicit: avoid
Genres that fit: lofi, ambient, classical, jazz
